01 / about

Who's behind the schema

I graduated in Computer Science from Yanbu Industrial College on a Database Administration track, then spent a 28-week co-op at the Industrial Research & Development Agency (RCJY) working close to real production systems.

My comfort zone is the relational world: SQL Server and MySQL, schema design, normalization, indexing, and query optimization. Right now I'm extending into PostgreSQL, Linux, Python, and cloud data tooling — the skills that turn a DBA into a data engineer.

I like problems where correctness matters: access control, approval workflows, and data that has to stay consistent under pressure. If a system quietly does the right thing every time, I've done my job.
